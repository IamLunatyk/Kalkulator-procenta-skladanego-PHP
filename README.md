Compound Interest Calculator
A lightweight Compound Interest Calculator built with HTML, CSS, JavaScript, and PHP. The application calculates investment growth using compound interest and presents the results dynamically in a table.

Features
Real-time calculations based on user input
Dynamic result table for easy data interpretation
Minimalist UI for seamless user experience
Fast and efficient backend processing with PHP
Technologies Used
Frontend: HTML, CSS, JavaScript
Backend: PHP (handles calculations and data processing)
